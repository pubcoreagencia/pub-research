## O que é / Para que serve
**Neural OS** = Repositório que contém o **PUB MASTER MEGA BLASTER CONTEXT** — o contexto mestre institucional consolidado da PUB Core Holding. Não é um "OS" no sentido tradicional, mas sim o **documento de autoridade canônica** que une todos os projetos, marcas, arquitetura, governança e infraestrutura da holding.

## Conteúdo do Master Context
1. **Como foi construído** — Cruzamento de 4 classes de evidência (contexto institucional, Library PUB, auditorias, histórico Git)
2. **Níveis de confiança** — VERIFIED (repo/artifact/institutional), HISTORICAL, CONFLICTING, NEEDS REVALIDATION, CONCEPT/TARGET
3. **Regra de Autoridade** — Hierarquia: Holding → Master Context → Project Master Context → Task Context → Agent → Execution
4. **Identidade Institucional** — Holding de tecnologia, negócios, mídia, serviços, entretenimento, criação de produtos/empresas replicáveis
5. **Ecossistema integrado** — Marcas/produtos/verticais compartilham: tecnologia, IA, agentes, infra, dados, marketing, vendas, operações
